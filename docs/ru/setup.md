## Требования

- **Windows 10 (22H2) / 11** (x64 или ARM64)
- **USB-адаптер Bluetooth для BlueCaster**: рекомендуется отдельный USB-адаптер. Встроенный USB-адаптер тоже подойдёт, но тогда в Windows не останется своего Bluetooth (см. [Шаг 2](#winusb))

BlueCaster сам назначает адаптеру драйвер WinUSB, поэтому [Zadig](https://zadig.akeo.ie/) больше не нужен (хотя он по-прежнему работает, см. [Использование Zadig](#zadig)).

## Установка BlueCaster

Каждый [выпуск](https://github.com/SeiyaFunaokaJP/BlueCaster/releases) выходит в двух вариантах с одинаковыми файлами:

- **Установщик** (`BlueCaster-<version>-win64-setup.exe`, для ARM64 — `-arm64-setup.exe`): устанавливает программу для текущего пользователя без прав администратора, добавляет пункт **BlueCaster** в меню «Пуск» и программу удаления. Если на компьютере нет Microsoft Edge WebView2 Runtime, установщик установит и её (в Windows 11 она уже есть). Обновления устанавливаются из самого приложения (**Параметры > Обновления > Обновить сейчас**). Программы устанавливаются в `%LOCALAPPDATA%\BlueCaster\`: три программы, программа удаления и папка `licenses\` с текстами лицензий
- **Портативная версия** (`BlueCaster-<version>-win64-portable.zip`, для ARM64 — `-arm64-portable.zip`): распакуйте архив в любое место и запустите `bluecaster.exe`. Три программы (`bluecaster.exe`, `bluecaster-core.exe`, `bluecaster-driver.exe`) должны лежать в одной папке. Портативная версия только сообщает о новых версиях, а WebView2 Runtime для неё нужно установить самостоятельно

Оба варианта хранят настройки, профили, ключи связи и прошивки в `%APPDATA%\BlueCaster`, поэтому между ними можно переключаться. При удалении программы эта папка удаляется, если не снять флажок **Удалить данные пользователя** (при тихом удалении она сохраняется).

### Переход с v1 {#from-v1}

Запустите установщик поверх v1. На странице **Всё готово к установке** перечислены предыдущие версии, которые он сначала удалит (v1 или любая 2.0.x). Если v1 запущена, установщик попросит её закрыть. Затем он удалит v1, но сохранит папку настроек: профили, сопряжения с наушниками и файлы прошивки перейдут в новую версию, и наушники не придётся сопрягать заново. Если адаптеру уже назначен WinUSB (через Zadig), он сохранится. Если был включён параметр **Запускать вместе с Windows**, теперь вместе с Windows будет запускаться v2.

При первом запуске v2 сначала копирует настройки v1 в `%APPDATA%\BlueCaster\backup\v1\`, а затем читает их.

### Переход с 2.0.x (A2DP Windows Bridge) {#from-2x}

BlueCaster 3.0.0 — это новое название A2DP Windows Bridge. Запустите установщик 3.0.0 поверх установленной 2.0.x: он автоматически удалит старую версию и сохранит ваши настройки. Пункт в меню «Пуск» и запись автозапуска (**Запускать вместе с Windows**) будут переименованы в «BlueCaster».

При первом запуске 3.0.0 переименовывает папку `%APPDATA%\A2DPWB` в `%APPDATA%\BlueCaster` и раскладывает файлы по вложенным папкам (см. [Настройки и файлы](architecture#settings-and-files)). В `backup\v2\` хранится копия настроек и сопряжений 2.0.x на случай, если вы захотите вернуться к 2.0.2: для этого скопируйте эти файлы обратно в `%APPDATA%\A2DPWB`.

Наушники могут показывать старое имя Bluetooth «A2DPWB», пока вы не выполните сопряжение заново.

## Шаг 1. Настройка при первом запуске {#first-run}

Подключите USB-адаптер Bluetooth и запустите BlueCaster. При первом запуске (если аудиоустройств ещё нет или ни одному адаптеру не назначен WinUSB) BlueCaster открывает **Мастер настройки** из четырёх шагов. Если пройти или пропустить мастер, он больше не откроется автоматически. Устройства затем добавляются на экранах **Главная** или **Аудиоустройства**.

1. **Выбор адаптера**: список найденных USB-адаптеров Bluetooth. Если вашего адаптера нет, подключите его и нажмите **Обновить**. Зелёная метка **Поддерживается** или красная **Не поддерживается** показывает, может ли BlueCaster использовать адаптер. Неподдерживаемые адаптеры видны в списке, но выбрать их нельзя
2. **Драйвер и прошивка**: шаг показывает, что будет сделано, а кнопка **Настроить этот адаптер** выполняет эти действия. BlueCaster заменяет драйвер адаптера на WinUSB (Windows запросит права администратора, см. [Шаг 2](#winusb)) и скачивает нужные файлы прошивки Realtek (см. [Прошивка](#firmware)). Прошивку, которую BlueCaster не может скачать, нужно скопировать в папку прошивки вручную. Если в Windows через этот адаптер сопряжены устройства (например, клавиатура или мышь на встроенном адаптере), кнопка сначала покажет их список. Пока адаптер занят BlueCaster, эти устройства не будут работать в Windows; кнопка **Отмена** оставит их в рабочем состоянии. Устройств с собственным USB-приёмником это не касается. Чтобы сохранить остальные, используйте BlueCaster с отдельным USB-адаптером. Кнопка **Заменить на драйвер WinUSB** на экране **Адаптеры** тоже показывает этот список
3. **Поиск аудиоустройств**: поиск запускается автоматически. Переведите аудиоустройство в режим сопряжения и нажмите **Подключить** рядом с ним (или введите его адрес и нажмите **Использовать**). BlueCaster сохранит устройство с лучшим поддерживаемым кодеком («Авто») и подключится к нему. Устройство появится в разделе **Сопряжённые устройства** с индикатором состояния, а поиск остановится. Кнопка **Добавить устройство** отключает его и снова запускает поиск, чтобы добавить ещё одно устройство. Первое устройство остаётся сохранённым, а лишнее устройство там же можно удалить. Раздел **Импортировать сопряжения из Windows** появляется, если Windows сопрягала устройства через этот адаптер: кнопка **Импортировать** показывает их список, где все устройства отмечены (см. [Шаг 3](#headphones)). Кнопка **Далее** работает и без устройства: аудиоустройства можно добавить позже на экране **Аудиоустройства**. Новые устройства захватывают звук с **Hi-Fi Cable**, если он установлен, а иначе — с VB-CABLE. Hi-Fi Cable даёт наименьшую задержку, поэтому его рекомендуется использовать для звука, а VB-CABLE — для микрофона наушников. Если какого-то кабеля нет, на шаге появляется предупреждение со ссылкой **Подробнее**, где перечислены оба кабеля. Кнопка **Установить** у VB-CABLE скачивает пакет VB-CABLE с сайта VB-Audio (1,3 MB) и устанавливает его. Windows запросит права администратора; если запрос не появился, перезагрузите Windows. Кнопка **Скачать** у Hi-Fi Cable открывает страницу VB-Audio. Для установленного кабеля вместо этого показана кнопка **Удалить**. Оба кабеля — donationware от VB-Audio ([vb-cable.com](https://vb-cable.com/)), как указано в разделе **О программе**. BlueCaster не содержит VB-CABLE, а пожертвования получает VB-Audio. Компании и другие организации VB-Audio просит покупать лицензию на каждую установку ([лицензирование](https://vb-audio.com/Services/licensing.htm)). Если BlueCaster позже впервые обнаружит кабель, устройства с источником **Устройство по умолчанию** начнут захватывать звук с него (с VB-CABLE — только если Hi-Fi Cable не установлен). Устройства, у микрофона которых нет рабочего выхода, начнут выводить микрофон в этот кабель. Кодек можно изменить позже на экране **Кодеки**
4. **Общие настройки**: тема, **Запуск**, **Уведомления** и проверка обновлений. Это те же элементы, что и в параметрах, и изменения сохраняются сразу. При первой настройке включаются **Запускать вместе с Windows** и **Запускать в области уведомлений**

Кнопка **Настроить позже** пропускает оставшиеся шаги. Снова открыть мастер можно через **Параметры > Запустить настройку**.

## Шаг 2. Назначение адаптеру драйвера WinUSB {#winusb}

BlueCaster работает с USB-адаптером Bluetooth напрямую через WinUSB — универсальный драйвер USB, встроенный в Windows. Рекомендуется **отдельный адаптер**: тогда встроенный Bluetooth продолжит работать в Windows как обычно.

1. Откройте экран **Адаптеры** (на шаге мастера **Драйвер и прошивка** кнопка **Настроить этот адаптер** выполняет шаги 2–4 сама)
2. В строке **Драйвер** адаптера указано **Исходный драйвер** (или **Нет драйвера**). Это драйвер от Windows или производителя, который будет заменён на WinUSB. Нажмите **Заменить на драйвер WinUSB**
3. Прочитайте подтверждение и продолжите. Windows запросит права администратора (UAC)
4. Теперь в строке драйвера указано **Драйвер WinUSB**

Если Windows не может сразу загрузить WinUSB (потому что адаптер занят), BlueCaster сообщит об этом, а в строке драйвера появится **Переподключите адаптер или перезагрузите Windows**. Отключите адаптер и подключите его снова; если адаптер встроенный, перезагрузите Windows. До этого подключение не удастся, а в журнале будет ошибка `failed to initialize WinUSB (error 50)`.

{: .warning }
Пока адаптеру назначен WinUSB, Bluetooth Windows этот адаптер не видит. Устройства, сопряжённые с Windows через него, не работают, пока вы не восстановите драйвер. Для обычной периферии (клавиатура, мышь и т. д.) используйте встроенный Bluetooth. BlueCaster можно отдать и встроенный адаптер, если это USB-устройство (на многих ноутбуках это адаптер Realtek). Но тогда **у ПК совсем не будет Bluetooth Windows** (ни параметров Bluetooth, ни мышей, клавиатур и других аудиоустройств), пока вы не восстановите драйвер адаптера.

Кнопка **Восстановить исходный драйвер** на том же экране возвращает адаптер Windows. Windows снова выбирает свой драйвер (обычно драйвер Bluetooth), и адаптер работает с Bluetooth Windows. Пока WinUSB не назначен снова, BlueCaster не сможет передавать через него звук. Windows работает только с одним адаптером Bluetooth одновременно. Если активен другой адаптер, BlueCaster сообщит об этом после восстановления. Чтобы использовать этот адаптер в Windows, отключите другой в диспетчере устройств и переподключите этот. Наушники, которые BlueCaster сопряг заново, получили новый ключ. Если Windows раньше сопрягала эти наушники через этот адаптер, при восстановлении новый ключ передаётся Windows, и наушники подключаются там без повторного сопряжения. **Ограничение:** передаются только классические сопряжения, ключи LE не передаются. Устройство, которое Windows использует через LE (LE Audio), нужно заново сопрячь в Windows (в режиме разработчика можно попробовать передать ключи LE: **Разработчик > Отладка**). Программа удаления предлагает то же самое. На одной из страниц мастера удаления есть флажки **Восстановить исходный драйвер Bluetooth** (если BlueCaster переводил адаптеры на WinUSB; один запрос прав администратора) и **Удалить данные пользователя** (настройки, кодеки, сопряжения и прошивки в `%APPDATA%\BlueCaster`, а также то, что запоминает окно, например **Показывать только поддерживаемые кодеки**). Оба флажка по умолчанию установлены. Если WinUSB назначен только адаптерам, настроенным через Zadig или v1 (о них у BlueCaster нет записи), первый флажок показан, но снят. Если его установить, драйвер для таких адаптеров выберет Windows. Обновления сохраняют WinUSB, как и тихое удаление (`/S`). Для установленных кабелей на той же странице есть флажки **Удалить VB-CABLE** и **Удалить Hi-Fi Cable**. По умолчанию они сняты, потому что кабели могут использовать другие приложения. Кабели удаляются без окна установщика VB-Audio, после запроса прав администратора от Windows. Затем Windows обновляет конфигурацию оборудования, чтобы кабель исчез из списка звуковых устройств. Перезагрузка предлагается, только если кабель всё ещё в списке.

### Использование Zadig {#zadig}

Драйвер WinUSB, установленный через [Zadig](https://zadig.akeo.ie/), работает так же хорошо:

1. Откройте Zadig и выберите **Options > List All Devices**
2. Выберите свой USB-адаптер Bluetooth в раскрывающемся списке
3. Выберите **WinUSB** в качестве целевого драйвера и нажмите **Replace Driver**

### Вручную в диспетчере устройств {#device-manager}

Если адаптера нет в списке BlueCaster, кнопка на экране **Адаптеры** не срабатывает или адаптер ведёт себя не так, как другие такие же, всё это можно сделать вручную в диспетчере устройств Windows (щёлкните правой кнопкой мыши **Пуск** > **Диспетчер устройств**). Для обоих действий нужны права администратора. Названия пунктов меню в разных версиях Windows могут немного отличаться.

**Заменить на драйвер WinUSB**

1. Найдите адаптер. Обычно он находится в разделе **Bluetooth** под своим именем (например, «TP-Link Bluetooth USB Adapter») или отмечен жёлтым значком, если его драйвер не запустился. Отличить его от встроенного Bluetooth компьютера помогает **Вид > Устройства по подключению**. Встроенный адаптер не трогайте, если не хотите отдать его BlueCaster
2. Щёлкните адаптер правой кнопкой мыши > **Обновить драйвер** > **Найти драйверы на этом компьютере** > **Выбрать драйвер из списка доступных драйверов на компьютере**
3. Если Windows спросит тип устройства, выберите **Устройства USB**. Снимите флажок **Только совместимые устройства**, выберите изготовителя **WinUsb Device** и модель **WinUsb Device**, нажмите **Далее** и подтвердите предупреждение
4. Теперь адаптер отображается как **WinUsb Device** в разделе **Устройства USB**. Перезапустите BlueCaster (или снова откройте экран **Адаптеры**): адаптер будет работать так же, как после Zadig

**Восстановить исходный драйвер**

1. В разделе **Устройства USB** щёлкните адаптер (**WinUsb Device**) правой кнопкой мыши > **Удалить устройство**. Если драйвер WinUSB устанавливался через Zadig, установите также флажок **Попытаться удалить драйвер для этого устройства**, иначе Windows снова выберет драйвер Zadig
2. Отключите адаптер и подключите его снова (или выберите **Действие > Обновить конфигурацию оборудования**). Windows установит свой драйвер, и адаптер появится в разделе **Bluetooth**
3. Если адаптер отмечен там жёлтым значком (драйвер не запустился, например код 31), драйвер производителя с ним не работает. Щёлкните адаптер правой кнопкой мыши > **Обновить драйвер** > **Найти драйверы на этом компьютере** > **Выбрать драйвер из списка доступных драйверов на компьютере** > **Generic Bluetooth Adapter**. Или снова назначьте WinUSB, как описано выше, чтобы использовать адаптер с BlueCaster

## Шаг 3. Поиск наушников {#headphones}

Кнопка **Найти устройства** (на экране **Аудиоустройства**) в течение 30 секунд ищет устройства поблизости через USB-адаптер и показывает их по мере ответа. В мастере настройки поиск запускается автоматически и идёт, пока не подключится устройство (**Добавить устройство** отключает его и продолжает поиск), пока вы не нажмёте **Остановить поиск** или не закроете мастер. Сначала переведите наушники в режим сопряжения. Устройства, с которыми BlueCaster уже выполнял сопряжение, отмечены как **Сопряжено**.

Если поиск не находит наушники, введите их адрес Bluetooth в поле **Вручную:** и нажмите **Использовать**. BlueCaster форматирует введённый или вставленный адрес на лету: `AA:BB:CC:DD:EE:FF`, `aa-bb-cc-dd-ee-ff`, `AABBCCDDEEFF` и `AA BB CC DD EE FF` превращаются в `AA:BB:CC:DD:EE:FF`.

Если Windows сопрягала наушники через этот адаптер до назначения WinUSB, это сопряжение можно сохранить. Раздел **Импортировать сопряжения из Windows** (на шаге мастера с устройствами; появляется, если такие устройства есть) показывает их список, где все устройства отмечены, и переносит отмеченные. После этого они подключаются без режима сопряжения. Windows запросит права администратора. Такое устройство обычно не находится в режиме сопряжения, поэтому при поиске его не видно. Если оно всё же нашлось или вы ввели его адрес, кнопки **Подключить** и **Добавить** сначала предупредят, что устройство сопряжено в Windows. Кнопка **Всё равно добавить** выполнит сопряжение заново, как с новым устройством.

**В параметрах Windows** (если наушники сопряжены со встроенным Bluetooth компьютера):
1. Откройте **Параметры > Bluetooth и устройства**
2. Выберите своё аудиоустройство
3. Нажмите **Свойства**
4. Там будет указан адрес Bluetooth (в формате `AA:BB:CC:DD:EE:FF`)

**Из командной строки** (сначала закройте BlueCaster: область уведомлений > **Выход**):
```
bluecaster-core.exe --cli --scan
```

У новых наушников выбран кодек **Авто** (**Кодеки**), а источником звука служит системный звук (**Аудиоустройства**). С этими значениями по умолчанию звук будет наилучшим. Обо всём остальном см. [Использование](usage).

## Прошивка (адаптеры Realtek) {#firmware}

USB-адаптерам Bluetooth на чипах Realtek (например, TP-Link UB500 и адаптерам на RTL8761BU) для работы нужна проприетарная прошивка. Адаптерам CSR прошивка не нужна. Адаптерам Intel, MediaTek MT79xx, Qualcomm и Broadcom могут понадобиться свои файлы прошивки: см. [Рекомендуемые адаптеры](#adapters).

### В приложении (пошаговое скачивание)

Экран **Адаптеры** (и шаг мастера **Драйвер и прошивка**) показывает состояние прошивки адаптера: **Прошивка в порядке**, **Файлы Realtek не нужны** (адаптер, который BlueCaster не распознал, с чипом **Не Realtek**) или **Прошивка не найдена** с именами нужных файлов. Кнопка **Открыть страницу загрузки** открывает в браузере страницу [linux-firmware/rtl_bt](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/rtl_bt), а кнопка **Открыть папку прошивки** — папку, куда нужно положить файлы. Скачайте нужные файлы `.bin` и поместите их в папку прошивки.

У адаптеров других производителей нет выбора **Чип Bluetooth**. Вместо него метка показывает, откуда берётся прошивка: **Из драйвера MediaTek** или **Из драйвера Qualcomm** (из драйвера производителя для Windows, который остаётся установленным и после WinUSB), **Из драйвера Wi-Fi** (Marvell; не выключайте Wi-Fi), **Из папки прошивки** (Intel, с кнопками **Открыть страницу загрузки**, **Открыть папку прошивки** и **Руководство по настройке**), **Необязательно** (`.hcd` для Broadcom) или **Не требуется** (CSR, Barrot, Actions). Когда BlueCaster загрузит прошивку через WinUSB, на метке появится **Загружена**, а если загрузка не удалась — **Не загружена**. Рядом будут кнопки **Открыть страницу загрузки**, **Открыть папку прошивки** и строка о том, откуда берётся прошивка.

Адаптеру на RTL8761B (например, TP-Link UB500) скачивать прошивку не нужно, если на компьютере установлен драйвер Realtek для Windows. Тогда BlueCaster использует прошивку из этого драйвера. Драйвер остаётся установленным и после перевода адаптера на WinUSB. Чтобы загрузить другую прошивку, например для Linux, нажмите **Использовать свою прошивку** в блоке прошивки адаптера на экране **Адаптеры**. После этого BlueCaster загружает файлы из папки прошивки. Чтобы вернуться к прошивке драйвера, нажмите **Использовать прошивку драйвера**.

Для чипов из списка **Чип Bluetooth** кнопка **Скачать прошивку** сделает всё сама. После подтверждения BlueCaster скачивает файлы из linux-firmware (kernel.org), сверяет каждый с ожидаемой суммой SHA-256 и сохраняет в папку прошивки. Если в linux-firmware нет файла конфигурации для чипа, BlueCaster сохраняет пустой `_config.bin`, и чип использует собственные настройки. Эти файлы не входят в BlueCaster и скачиваются только по вашему запросу.

BlueCaster определяет чипсет адаптера и показывает, какие файлы прошивки нужны.

Без прошивки адаптер Realtek всё равно открывается и отвечает, работая на коде из ПЗУ, поэтому выглядит исправным. Но подключение или передача звука не удаются, и BlueCaster сообщает, что прошивка не загружена. Адаптер хранит прошивку, загруженную в предыдущем сеансе, пока на него подаётся питание. Поэтому даже после удаления файлов он может работать, пока вы не перезагрузите ПК или не отключите адаптер.

### Параметр «Чип Bluetooth»

Список **Чип Bluetooth** на экране **Адаптеры** определяет, выполняет ли BlueCaster для адаптера инициализацию Realtek (загрузку прошивки):

| Вариант | Значение |
|:--------|:---------|
| **Авто** (по умолчанию) | Выбор делается при каждом запуске BlueCaster по обнаруженному адаптеру. Для известного адаптера Realtek выбирается его чип; для остальных адаптеров инициализация Realtek не выполняется |
| **Не Realtek** | Инициализация Realtek никогда не выполняется. Выберите этот вариант для адаптеров Intel, Broadcom, CSR и других, если «Авто» не распознаёт ваш адаптер |
| **RTL8761BU**, **RTL8822CU**, ... | Указанный чип Realtek. Нужен для адаптера на чипе Realtek, который «Авто» не распознаёт (OEM-устройство под собственным VID:PID). Строка состояния показывает, есть ли файлы `.bin` этого чипа в папке прошивки |
| **Custom** | Используются `custom_fw.bin` и `custom_config.bin` из папки прошивки |

Не выбирайте чип Realtek или Custom для адаптера не на Realtek: BlueCaster попытается загрузить в него прошивку Realtek, и адаптер может не запуститься.

### Скачивание вручную

1. Скачайте файлы прошивки и конфигурации `.bin` для своего чипсета из [linux-firmware/rtl_bt](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/rtl_bt) (например, `rtl8761bu_fw.bin` и `rtl8761bu_config.bin`)
2. Поместите оба файла в папку прошивки BlueCaster (`%APPDATA%\BlueCaster\firmware`; её также открывает кнопка **Открыть папку прошивки**)

{: .note }
Эти файлы прошивки — проприетарные двоичные файлы Realtek, которые распространяются через проект linux-firmware. В этот репозиторий они не входят. Условия распространения см. в [WHENCE](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/WHENCE).

## Рекомендуемые адаптеры {#adapters}

Какие адаптеры и наушники уже использовались с BlueCaster, с кодеками и ссылками на отчёты, см. на странице [Проверенное оборудование](hardware).

| Чипсет | Примеры устройств | Примечания |
|:-------|:------------------|:-----------|
| Realtek | TP-Link UB500, RTL8761BU | Использует прошивку из драйвера Realtek для Windows, если он установлен; иначе скачайте прошивку (см. выше). Проверен лучше всего |
| Realtek | RTL8852BD (`0BDA:B853`), RTL8852BT, RTL8922A | BlueCaster читает прошивку (например, `rtl8852bd_mp_chip_new.dat`) из драйвера Bluetooth Realtek для Windows, поэтому не удаляйте этот драйвер. Иначе поместите в папку прошивки файл, указанный в журнале. На реальном оборудовании ещё не проверялись |
| CSR | Типовые USB-адаптеры CSR8510 | Работают сразу, прошивка не нужна |
| Barrot | USB-адаптеры Bluetooth 5.4 / 6.0 (`33FA:0010`, `33FA:0012`) | Работают на прошивке из ПЗУ, загружать прошивку не нужно. Пока есть только одно сообщение пользователя |
| Marvell | Встроенный в Microsoft Surface Pro / Surface Book (88W8897) | Файлы прошивки не нужны: прошивку Bluetooth загружает драйвер Wi-Fi, поэтому не выключайте Wi-Fi. На реальном оборудовании ещё не проверялся |
| Actions | USB-адаптеры ATS2851 (`10D7:B012`) | Работают на прошивке из ПЗУ, загружать прошивку не нужно. Адаптер заявляет команды, которые не поддерживает; BlueCaster их скрывает. На реальном оборудовании ещё не проверялись |
| Broadcom | ASUS BT400 (BCM20702), другие USB-адаптеры и модули ноутбуков на BCM20702 / BCM20703 / BCM43142 | Распознаются и адаптеры, которые сообщают вендорный класс `FF/01/01` вместо класса Bluetooth `E0/01/01` (OEM-адаптеры на BCM20702). Работает на прошивке из ПЗУ. Если установлен драйвер Bluetooth Broadcom для Windows, BlueCaster при запуске загружает патч из этого драйвера. Если в папке прошивки есть файл PatchRAM `.hcd` (например, `BCM20702A1-0b05-17cb.hcd`), BlueCaster использует этот файл вместо патча драйвера. Если патч драйвера не загрузился, BlueCaster просит отключить адаптер и снова подключить его. После этого BlueCaster больше не загружает патч в этот адаптер. Патч драйвера на реальном оборудовании ещё не проверялся |
| Intel | Intel 7260 / 3160 / 7265 / 3165 / 3168 / 8260 / 8265 / 9260 / AX200 / AX201 / AX210 / AX211 | В режиме загрузчика (например, после холодного запуска) в папке прошивки нужны подходящие `ibt-*.sfi` + `ibt-*.ddc` из папки `intel/` пакета linux-firmware. Их имена указаны в журнале (например, `ibt-0180-0041.sfi`). 7260 / 3160 / 7265 / 3165 / 3168 работают из ПЗУ и файлов не требуют; если в той же папке есть подходящий патч `ibt-hw-*.bseq`, он применяется |
| MediaTek | MT7925, MT7927, MT7922, MT7921, MT7902 (карты Wi-Fi, например AMD RZ717, RZ738, RZ616, RZ608) | Нужен файл чипа `BT_RAM_CODE_MT*_hdr.bin` (например, `BT_RAM_CODE_MT7925_1_1_hdr.bin`). Если установлен драйвер Bluetooth MediaTek для Windows, BlueCaster берёт файл из него. Иначе поместите в папку прошивки указанный в журнале файл из папки `mediatek/` пакета linux-firmware. MT7927 на реальном оборудовании ещё не проверялся |
| Qualcomm | QCA61x4, QCA9377 (ROME), WCN6855 (FastConnect 6900), WCN785x (FastConnect 7800) | Нужны rampatch и NVM чипа (например, `AthrBT_0x00000302.dfu` и `ramps_0x00000302_48.dfu`). Если установлен драйвер Bluetooth Qualcomm для Windows, BlueCaster берёт файлы из него. Иначе поместите в папку прошивки указанные в журнале файлы из папки `qca/` пакета linux-firmware (`rampatch_usb_*.bin`, `nvm_usb_*.bin`). На реальном оборудовании ещё не проверялись |
| MediaTek | MT7663 | Нужен файл патча чипа (например, `mt7663_patch_e2_hdr.bin`). Если установлен драйвер Bluetooth MediaTek для Windows, BlueCaster берёт файл из него. Иначе поместите в папку прошивки файл, указанный в журнале. На реальном оборудовании ещё не проверялся |
| Qualcomm Atheros | AR3012 и другие чипы AR30xx (Bluetooth 4.0 в старых ноутбуках) | Нужны файлы патча и конфигурации чипа (например, `AthrBT_0x31010000.dfu` и `ramps_0x31010000_40.dfu`). Если установлен драйвер Bluetooth Qualcomm Atheros для Windows, BlueCaster берёт файлы из него. Иначе поместите файлы в папку прошивки; их имена указаны в журнале. На реальном оборудовании ещё не проверялись |
| MediaTek, Qualcomm | Более старые чипы MediaTek (например, MT7630 и MT7650), другие чипы Qualcomm (QCA6290) | Не поддерживаются: для них нужны загрузчики прошивки, которых в BlueCaster нет ([помогите добавить](chip-support)) |

Для кодеков с высоким битрейтом, таких как LDAC, обычно лучше всего подходят USB-адаптеры Bluetooth 5.0 и новее.

Если WinUSB назначен нескольким адаптерам, BlueCaster использует первый найденный, если на экране **Адаптеры** на карточке другого адаптера не нажата кнопка **Использовать этот адаптер**. Адаптер, который сейчас используется, отмечен как **Используется**.
